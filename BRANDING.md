# Branding checkpoint

The application now plans workstation agents, local administration, and an Ubuntu web dashboard/API, with future secured remote actions. The existing repository name describes only the original feature. Product branding is provisional. No rename, domain purchase, DNS change, registration or legal clearance is performed by this document.

## Candidates and preliminary web observations

- StationPilot: preferred early working name, but a close software-name collision exists with DTF Station Pilot printer-control software. Do not call the name cleared. Source: https://kolormatrix.com/pages/dtf-station-pilot-software-guide-for-dtf-printers
- SessionPilot: already used by multiple products, including therapy documentation and gaming-session tools; recommend dropping it. Sources: https://sessionpilot.app/ and https://sessionpilot.net/about/
- StationSignal: no obvious exact-match software product found in the preliminary search on 2026-10-15. Search absence is not proof of availability, uniqueness, legal clearance or domain availability. Keep as a candidate only.

Do not derive trademark conclusions from differing industries or available domains. Complete a broader software/package/repository/name and appropriate trademark review before settling branding. Domain availability must be checked separately at a registrar. Domain purchase and any Cloudflare changes require a separately approved exact action.

## Identifier policy

Keep mjpcomp/locked-session-logoff and existing executable/service/project identifiers until a name is selected and approved. Plan distinct Agent, Console and Server labels after selection. Renaming must preserve upgrade/uninstall ownership, original-state ledger and credential/device identity, with documented migration. No cosmetic rename that breaks existing installation detection.
